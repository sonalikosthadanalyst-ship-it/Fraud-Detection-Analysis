# Fraud Detection Analysis (Excel & SQL)

## 📌 Project Overview
This project focuses on identifying **fraudulent transactions** by performing a combined analysis using **Excel** and **SQL**. It demonstrates end-to-end data processing—from cleaning raw data in Excel to running advanced queries in SQL to detect suspicious patterns.

## 🚀 Key Steps
1. **Data Cleaning (Excel):** Performed data validation, removed duplicates, and corrected data formats to ensure analysis accuracy.
2. **Database Management (SQL):** Imported the cleaned dataset into a MySQL database and structured it for efficient querying.
3. **Fraud Analysis (SQL):** Used advanced SQL queries (including Joins, Views, and Aggregate functions) to filter abnormal transactions and generate a detailed fraud report.

## 🛠️ Tech Stack
* **Excel:** For data cleaning and preprocessing.
* **SQL:** For storage, manipulation, and analysis.
* **Tool:** MySQL Workbench

## 📊 Business Impact
This analysis helps in spotting irregularities in transaction patterns, which is a critical skill for any Data Analyst working in the finance domain.
